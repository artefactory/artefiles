# cmux: Ghostty-based terminal with vertical tabs

Alternative to `ghostty`: pick one. macOS only (cask `manaflow-ai/cmux/cmux`).

- Vertical tabs and notifications when an agent (Claude Code, for example)
  waits for input.
- It reads the Ghostty config, so `~/.config/ghostty/config` (managed) applies
  to it too.
